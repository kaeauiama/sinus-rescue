# ハミングの構えと「響かせる」の定義(調査メモ)

- 状態: 調査メモ。2026-11-08 作成。ここでの提案は D-030〜D-035 で「いろいろ試す」方針として採用し、ハミングのメニュー(00-concept.md §6.4)になった。決まったことは [00-concept.md](00-concept.md) の Decision Log を正とし、このメモは根拠として参照する。
- 医療に関する記述は設計判断の材料であり、医学的助言ではない。
- 「推論」と書いたものは筆者(Claude)の考察で、文献で確かめていない。

## 1. 問い

- 震え方は音の高さだけでなく、口、鼻、その周りの筋肉の構えでも変わる。
- では「狙った副鼻腔を震わせる」とは、何を指すのか。目指すべきはその状態なのか。
- それを踏まえて、トレーニングとしてどう組み立てるか。

## 2. 分かったこと

### 2.1 ハミングで副鼻腔の空気が入れ替わる仕組み

| 内容 | 出典 |
|---|---|
| 鼻腔の中で交互に変わる圧力が、副鼻腔の開口部にある空気の栓を往復させ、中のガスを押し出す。押し出されたガスは吐く息で運ばれる | Granqvist 2006(管の模型と計算) |
| 模型では、副鼻腔の位置が圧力の節(振れがない場所)でなければ排出が増えた | Granqvist 2006 |
| NOのピークを最も左右するのは開口部の大きさで、ハミングの周波数も影響する。周波数の効果の向きと大きさは、要旨には書かれていない | Maniscalco 2003、学位論文 2006 |
| 開口部が完全に塞がるとピークは消える。アレルギー性鼻炎でピークが出ない人の多くに、内視鏡で開口部の閉塞を示す所見があった(11人中9人) | Maniscalco 2004、学位論文 2006 |
| 続けるとピークは段階的に下がり、3分の休止で完全に戻る | Maniscalco 2003 |

### 2.2 構えが音を変える仕組み

| 内容 | 出典 |
|---|---|
| 唇を閉じた「ん[m]」では、口の中全体が閉じた枝管になる。枝管は自分の共振周波数でエネルギーを吸い取り、出てくる音に谷(反共振)を作る。口腔を8cmの管とみると、谷はおよそ1000Hzと3000Hz | Hoole の講義ノート(Johnson の教科書を参照) |
| 舌で閉じる位置を奥にすると(「ん[n]」「ん[ŋ]」)、枝管が短くなり、谷は高い周波数へ移る | 同上 |
| 鼻音の第1共鳴は約300Hz。帯域幅は母音の約3倍(60Hzに対して200Hz)で、減衰が大きい | Fujimura 1962(Pruthi 2004 経由)、Hoole |
| 副鼻腔も枝管として働き、3人の測定で310〜1070Hzに谷を作った。個人差と左右差が大きい | Dang & Honda 1996(00-concept R-7 で既出) |
| 声帯の閉じ方が中くらい(強く押しつけず、息も漏らさない)のときに、口腔の音圧が最大になった | Zhang 2022(計算モデル) |
| 声楽家が「頭の響き」を出すと、軟口蓋が上がり(鼻への道が狭まり)、喉頭の入口が狭くなった | 頭の響きと imposto の内視鏡研究 2022(5人) |

**推論(§9のモデルでほぼ否定):** 「ん[m]」で口腔が作る谷(約1000Hz)は、副鼻腔の帯域(310〜1070Hz)の上の方と重なるので、「ん[ŋ]」にすれば倍音が鼻腔へ多く届くと考えた。モデルでは450Hz以上で開口部の圧が4〜6dB上がったが、声全体で見た栓の動きは1dB未満しか変わらなかった。栓を動かすのは主に低い倍音で、口腔の谷はそこまで届かないためである。

**推論:** 低い周波数では、鼻の穴(開いた端)が圧力の節になる。鼻の奥ほど圧力の振れが大きく、鼻づまりで通り道が細いほど振れは大きくなるはずである。

### 2.3 体感が示すもの

| 内容 | 出典 |
|---|---|
| 鼻の外側の皮膚の振動は、鼻への響き(鼻音化)の指標として研究で使われている。声の大きさで割った比(HONC)が、聞いた印象の鼻声とよく対応した | Horii 1980、1983(鼻音化の研究での引用から。原典は未確認) |
| 声楽の「仮面の響き」は、骨伝導と組織の共振による感覚と説明されることが多い。副鼻腔が音にもたらす寄与は小さいとする見方が多いが、決着をつけた研究は見つからなかった | 声楽の解説記事、耳鼻科医の解説 |
| 顔や頭の振動感は、軟口蓋が上がって鼻への道が狭まっていても生じる | 頭の響きの内視鏡研究 2022 |

まとめると、**鼻の周りの振動感は「音が鼻に入っているか」をある程度示す**。一方で、**体感の場所から、どの副鼻腔の空気が動いたかは判定できない。**

### 2.4 解剖

前頭洞、上顎洞、前篩骨洞の開口部は、どれも中鼻道に集まる。後篩骨洞は上鼻道へ、蝶形骨洞は鼻の奥上部の蝶篩陥凹へ開く(一般的な解剖学の知識)。中鼻道に生じた圧力の振動は、複数の副鼻腔に同時に届く。

## 3. 「狙った副鼻腔を震わせる」の3つの定義

| 定義 | 内容 | 確かめられるか |
|---|---|---|
| 物理 | その副鼻腔の開口部で、空気の栓が強く往復している | 家庭では不可 |
| 機能 | その副鼻腔のガスが入れ替わる(ハミング中のNOのピーク) | NO測定器が必要 |
| 体感 | その部位の上の皮膚が震えると本人が感じる | 本人だけ。物理と機能との対応は未確認 |

物理の定義が成り立つには、次の4条件がそろう必要がある。

1. 開口部が開いている(体の状態で決まり、アプリでは変えられない)
2. 振動の成分のどれかが、その副鼻腔の共振の近くにある(基本の高さか、その倍音)
3. 開口部の位置が、その周波数で圧力の節になっていない
4. 振れが十分に大きい

アプリが扱えるのは体感だけで、体感は物理の定義を測る手段としては弱い。

## 4. 目指す状態

**提案:** 「特定の副鼻腔を狙う」ことは目標にしない。理由は次の3つ。

- 主な副鼻腔は中鼻道に開口部を共有していて、鼻腔の振動は複数に同時に届く。
- 共振は人によって違い、同じ人でも日によって変わりうる。開口部の大きさが粘膜の腫れで変わるからである(推論)。
- 体感の場所は骨伝導や喉の構えでも変わり、狙った副鼻腔に届いた証拠にならない。

代わりに、**「鼻への道が開いた楽な構えで、鼻腔の中に十分な振動を起こし、幅広い周波数を通り、休憩を挟んで繰り返す」**状態を目標にする。

| 条件 | 内容 | アプリで扱う方法 |
|---|---|---|
| 鼻への道 | 唇を閉じ、口から息が漏れず、鼻から息が出ている | 構えのチェック。音量の急な変化で確かめる案もある(§5) |
| 楽さ | 喉を締めない、押しつけない、大声にしない | 音量の目安の帯。めまいや耳の違和感で中止 |
| 振動の強さ | 楽な範囲で、鼻の周りがはっきり震える | 体感の評価。音量と合わせて記録 |
| 鼻の出口 | 鼻孔を指で軽く狭め、細く息が出る程度にする。鼻腔の圧の振れが大きくなり、息の流れも残る(§9) | 構えの候補の筆頭にする |
| 周波数の幅 | 1つの高さに固定せず、楽な範囲をゆっくり上下する区間を入れる。共振の近くを、基本の高さか倍音で必ず通る。鼻を開けたままなら高さの影響が大きく、狭めると小さい(§9) | 音程のガイドにグライド(上下の移動)を加える |
| 回復 | 続けすぎず、3分休む | 既存の短セットと休憩 |

「響く部位と音」の登録は、振動の強さを満たしやすくする個人の手がかりとして残す。意味を「副鼻腔の特定」から「自分の型を作る手がかり」に変える。

## 5. トレーニングの構成案

| 段階 | 内容 |
|---|---|
| 1. 基本の構え | 初回と、ときどき確認する。唇は軽く閉じる、奥歯は離す、舌は力を抜く、鼻から息が出ている、喉と肩の力を抜く、楽な大きさ。鼻の下に手をかざして息を感じる方法で確かめる |
| 2. 構えを比べる | 1回に1つだけ変えて比べる。モデルで差が大きかった順に、鼻の出口(開ける / 軽く狭める / つまんで口を小さく開ける)、高さとグライド、声の質(軽く / しっかり)。差が小さかった「ん[m] / ん[n] / ん[ŋ]」と舌や顎は、体感で差があるなら残す。順番は無作為にし、音量は実測して揃えるよう促す。評価は「どこが」「どれくらい」震えたか |
| 3. 自分の型 | 構え、高さ(またはグライドの範囲)、音量の組み合わせとして登録する。名前は体感の言葉で付ける(「鼻の奥が響く型」など) |
| 4. 今日のハミング | 型の合図(1行)→ セット → 3分休憩。グライドの区間を入れられる。表示は音程のズレ、音量の帯、残り時間 |
| 5. 確かめる | 週1回、比べる段階を短く行い、型を見直す。効果は翌朝の鼻の通りと比較実験で見る。比較の組み合わせに「固定の音とグライド」「ん[m]とん[ŋ]」を加えられる |

今のアプリにある「響きの登録」は段階2と3の一部(高さだけ)に当たり、「今日のハミング」は段階4に当たる。

## 6. 測れることを増やす案(どれも未検証)

| 案 | 内容 | 進め方 |
|---|---|---|
| 皮膚の振動を比べる | スマホのマイクを鼻の横や頬に当てて、構えの違いで振動の大きさを比べる。鼻の皮膚の振動を測る研究(HONC)と同じ考え方 | iPhoneのマイクの位置と当て方の再現性が課題。M0と同じく、検証ページで先に確かめる |
| 鼻への道の確認 | ハミング中に鼻を1秒つまむと音がほぼ止まることを、音量の変化で確かめる | 口を閉じたままつまむと出口がなくなり、圧が声帯の下の圧まで上がりうる。手をかざす方法を既定にする |
| 谷の位置を探す | グライドしながら鼻から出る音を分析し、副鼻腔が作る谷を探す | 研究段階。今は作らない |

## 7. やらないこと

- 「この音で前頭洞に届く」「副鼻腔が振動している」といった表示はしない。HC-1のガードで止まる。
- 鼻と口の両方を閉じたまま声を出させたり、息を強く押し込ませたりはしない。出口がなくなると、圧が声帯の下の圧まで上がりうる。鼻孔を狭める、または口を小さく開けてつまむ構えは、計算では平均の圧が0.1〜4cmH2O程度に収まる(§9)。耳が詰まった感じや痛みが出たら中止する。
- 大声や長時間を良いものとして誘導しない。

## 8. 未確認

- 周波数がNOの排出に与える効果の向きと大きさ。Granqvist 2006 と Maniscalco 2003 の全文は入手できていない。
- 「ん[m]」と「ん[ŋ]」で鼻腔の中の圧の振れが変わるか(§2.2の推論)。
- 体感の強さと、鼻腔の中の圧の振れの対応。
- スマホのマイクを皮膚に当てたときの計測の再現性。
- 鼻音の谷の帯域の原典の値。Fujimura 1962 は未確認で、講義ノートの概算に基づく。
- §9のモデルの寸法と損失は文献のおおよその値を当てはめた仮の値で、実測していない。鼻腔は左右をまとめた1本の管として扱い、甲介の複雑な形は損失の大きさだけで表した。
- 栓の往復で実際にどれだけガスが入れ替わるか。ハミング中の鼻腔内の音圧の実測値は見つけていない。

## 9. 管のモデルで比べた構え(2026-11-08)

### 9.1 モデル

`tools/hum-model/nasal_model.py`(`python tools/hum-model/nasal_model.py` で再計算できる)。声帯から咽頭、口腔、鼻腔をつないだ管を、損失のある伝送線路で計算した。副鼻腔は開口部の首と中の空気からなるヘルムホルツ共鳴器として、鼻腔の途中につないだ。

| 部分 | 仮の値 |
|---|---|
| 咽頭 | 9cm、3cm² |
| 口腔 | 8cm、3cm²。頬は柔らかい壁 |
| 軟口蓋の開き | 1cm、1cm² |
| 鼻腔 | 軟口蓋の出口から鼻孔まで10cm(左右合計2.5cm²)。最後の1.5cmは壁の柔らかい鼻前庭 |
| 蝶形骨洞 | 出口から2.5cmに開口。共振605Hz |
| 上顎洞 | 出口から5.5cm(中鼻道)に開口。片側15mL、開口部4mm²、首6mm。共振308Hz |
| 損失 | 母音の帯域幅が約60Hz、鼻音が約200Hzになるよう設定 |
| 声の音源 | 有限の抵抗をもつ音源。倍音は1オクターブごとに12dB弱くなるとした |

検算: 「ん[m]」で鼻孔から出る音は、250Hzに山、1100Hzに谷が出た。鼻音の第1共鳴(約300Hz)と、口腔の谷(約1000Hz)の文献値に近い。

| 鼻孔を狭める(0.2cm²) | +8 | +11 | +3 | あり | 0.9cmH2O |

### 9.3 「蓋」と「壁」

- 開いた管の出口(鼻孔)では、空気はよく動くが圧力は振れない(圧力の節)。閉じた管の端では、空気は動かず圧力が最も振れる(圧力の腹)。
- 鼻を開けたハミングでは、鼻先が圧力の節に近い(軟口蓋側を1として0.05)。上顎洞の開口部は0.49、蝶形骨洞は0.69で、奥の開口部ほど振れが大きい。
- 鼻をつまむと鼻腔は行き止まりの枝管になり、低い周波数では鼻腔全体がほぼ同じ圧で振れる(1.04〜1.13)。指と小鼻の「蓋」と、柔らかい鼻前庭はこの圧に押されて揺れる。鼻先の震えが最大になるのはこのためで、骨の壁はほとんど動かない。
- このとき蓋の震えは、開口部の圧の目安になる(蓋と上顎洞の開口部はほぼ同じ圧)。鼻を開けたハミングでは、鼻先の震えは開口部の圧を表さない。
- つまむ位置の違い: 鼻孔でつまむと、鼻前庭が閉じた空間に入り、柔らかい蓋と壁が揺れる。鼻先の震えは最も強いが、柔らかい部分は振動のエネルギーを少し吸う。小鼻でつまむと閉じる位置が約1.5cm奥に移り、鼻先は揺れにくくなるが、開口部の圧は0.5〜1dB高い。付け根は骨に近いので閉じきりにくく、すき間が残ると150Hzで7dBほど下がる(代わりに息が少し鼻を通る)。閉じる位置の違いが効くのは、行き止まりの管が共振する800Hz以上の倍音だけで、副鼻腔の帯域ではほとんど効かない。
- 副鼻腔の「栓」は壁でも蓋でもなく、開口部の首にある空気の塊で、中の空気がばねになる。栓は開口部の場所の圧に押され、自分の共振の近くで最もよく動く。

### 9.4 栓を動かすための条件

| 条件 | 理由 | 構えでの手段 |
|---|---|---|
| 開口部の場所の圧を上げる | 栓は開口部の圧に押されて動く | 鼻の出口を狭めるか閉じて、鼻孔の圧力の節をなくす。閉じるなら口の開きを小さくする |
| 栓の共振の近くに音を置く | 共振では同じ圧でも数倍動く | 鼻を開けるなら高さ選びが効く。狭めるか閉じると、130Hz以上で高さの影響が小さくなる |
| 押し出したガスを運ぶ流れを残す | Granqvist 2006 の仕組みでは、押し出されたガスは吐く息で運ばれる | 完全に閉じると鼻の中の息が止まり、出たガスは鼻腔にたまって戻りうる(推論)。狭める構えなら流れが残る。閉じる構えは、鼻を開けて息を流す時間と交互にする |
| 圧を上げすぎない | 耳と安全のため | 口か鼻のどちらかは必ず開けておく |

**推論(大きさの見積もり):** 共振より低い周波数では、栓が一往復で押す量は「副鼻腔の容積 × 圧 ÷ 空気のこわさ」で、上顎洞(15mL)で10Paなら約1μLになる。開口部の首の容積(4mm² × 6mm ≈ 24μL)よりずっと小さく、空気は首の中で行き来するだけに近い。共振で数倍になり、構えでさらに4倍になれば首の容積に近づき、1往復で入れ替わる量が大きく増えうる。鼻腔の中の音圧が分からないので、桁の見積もりにとどまる。

### 9.5 前の提案の修正

- 「ん[ŋ]」で副鼻腔の帯域に倍音が多く届くという推論は、モデルでは支持されなかった(§2.2)。
- 構えの比較で最初に試すべきなのは、「ん」の種類より鼻の出口である。
- 鼻孔を狭めるハミングを一律に勧めないとした §7 の方針は、計算した平均の圧が小さかったので、「鼻と口の両方を閉じない」「強く押し込まない」に改めた。
