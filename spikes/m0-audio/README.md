# M0 音声チェック

本体の実装前に、基準音とマイクが iPhone で使えるかを確かめる使い捨ての検証ページ。確認項目は [docs/00-concept.md](../../docs/00-concept.md) の §6.4 を参照。

```bash
npm test
```

```bash
npm run serve
```

URL に `?sim=1` を付けると、マイクの代わりに合成音を入力する。`&fast=1` で待ち時間を短縮する。どちらもブラウザ上の動作確認用で、iPhone 固有の挙動の確認にはならない。

音声は波形を読むだけで、保存も送信もしない。結果はページからコピーする JSON のみ。
